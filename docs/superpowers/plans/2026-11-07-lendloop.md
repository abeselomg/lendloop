# LendLoop Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build LendLoop, a neighborhood tool-lending board (Next.js + Clerk + Convex) with HMAC-secured, idempotent n8n automations for loan notifications and overdue reminders, verified locally and deployable to Vercel/Convex Cloud/Railway.

**Architecture:** Thin Next.js App Router pages talk to Convex through React hooks; all authorization lives in Convex functions keyed off the Clerk JWT. Loan status changes write to an outbox table and a scheduled action delivers signed webhooks to n8n with retries. n8n calls back into signed Convex HTTP actions that upsert by idempotency key; every failure path ends in an `automationLog` row the UI shows.

**Tech Stack:** Next.js 16.4.5, React 19.3, TypeScript 5, Tailwind 4, @clerk/nextjs 7.9.25, convex 1.49.0, convex-test 0.0.67, vitest 5.1.0, @edge-runtime/vm 5.0.0, n8n 2.46.6 (Docker), Resend REST API.

**Spec:** `docs/superpowers/specs/2026-11-07-lendloop-design.md` (acceptance checklist: `docs/assignment.md`)

## Global Constraints

- Company name is **LendLoop**; tagline "Borrow what you need. Lend what you don't."
- Pinned versions exactly as in Tech Stack; Node ≥ 20.
- Every Convex query/mutation that reads or writes user data goes through `requireUser`/`requireAdmin` from `convex/lib/access.ts`, except `tools.listPublic`.
- Public query returns only `{ _id, name, category }`.
- Categories: `power_tools | hand_tools | garden | kitchen | camping | cleaning | automotive | other`. Conditions: `new | good | fair | worn`. Loan statuses: `pending | approved | declined | returned | cancelled`.
- Dates are `YYYY-MM-DD` strings compared lexicographically; "today" is UTC.
- Signature scheme both directions: headers `x-lendloop-timestamp` (unix ms), `x-lendloop-signature` = `v1=<hex HMAC-SHA256(secret, `${timestamp}.${rawBody}`)>`, tolerance 5 minutes, constant-time compare, `x-lendloop-event-id` on POSTs.
- Env var names (never any other spelling): Next: `NEXT_PUBLIC_CONVEX_URL`, `NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY`, `CLERK_SECRET_KEY`. Convex: `CLERK_JWT_ISSUER_DOMAIN`, `N8N_LOAN_EVENT_WEBHOOK_URL`, `CONVEX_TO_N8N_SECRET`, `N8N_TO_CONVEX_SECRET`, `ADMIN_EMAILS`, `APP_URL`. n8n: `LENDLOOP_CONVEX_SITE_URL`, `CONVEX_TO_N8N_SECRET`, `N8N_TO_CONVEX_SECRET`, `LENDLOOP_EMAIL_ENABLED`, `LENDLOOP_EMAIL_FROM`, `RESEND_API_KEY` (import-time only, becomes credential "Resend API").
- No secrets in code or in `n8n/workflows/*.json` (Task 15 test enforces).
- Commit after every task with a conventional-commit message. Never commit `.env*` files.

## Review Focus

1. **Removed tool with an in-flight loan** — loan still renders (via `toolName` snapshot) in requests/incoming/admin and can still be returned. Test in Task 6.
2. **Webhook URL or secret missing in Convex env** — `deliverEvent` must mark the event failed with a readable error and log `webhook_failed`, not throw repeatedly. Test in Task 7.
3. **Malformed write-back from n8n** (bad JSON, unknown loan id, missing field) — 400 with a message, signature still required first; never a 500. Test in Task 8.
4. **Duplicate event delivery** (Convex retries after n8n's 202 was lost) — n8n's write-back for the same `eventId` must not create a second log row. Test in Task 8 (`recordNotification` twice).
5. **Day boundary** — a request for `startDate === todayUtc()` is valid; `endDate < today` is overdue only when strictly less. Tests in Task 2 and Task 8.
